---
title: "Clearing Your Browser's Cache"
weight: 3
---

Your browser keeps copies of the pages, scripts, styles and pictures that make up Healdan's interface, so it
starts quickly. Each time it opens Healdan, it checks with the server for a newer interface. But a tab left open
while Healdan was upgraded keeps running the old one, and styles and pictures are kept for longer, so after an
upgrade some copies can be out of date. When Healdan notices that your browser is running an older version than the
server, it shows a page asking you to clear your browser's cache and then sign in again.

## A Quick Reload

Often a hard reload is enough. With Healdan open, press:

- **Windows and Linux:** `Ctrl` + `Shift` + `R`
- **Mac, in Chrome, Edge or Firefox:** `Cmd` + `Shift` + `R`
- **Mac, in Safari:** `Option` + `Cmd` + `R`

## Clearing the Cache

If a hard reload doesn't help, clear the cache. You don't need to clear cookies or passwords.

{{< tabs >}}

{{< tab name="Chrome and Edge" >}}

1. Press `Ctrl` + `Shift` + `Delete` (`Cmd` + `Shift` + `Delete` on a Mac).
2. Choose **Cached images and files**, and untick everything else.
3. Click **Delete data** (Chrome) or **Clear now** (Edge).

{{< /tab >}}

{{< tab name="Firefox" >}}

1. Press `Ctrl` + `Shift` + `Delete` (`Cmd` + `Shift` + `Delete` on a Mac).
2. Choose **Temporary cached files and pages**, and untick everything else.
3. Click **Clear**.

{{< /tab >}}

{{< tab name="Safari" >}}

1. If the menu bar has no **Develop** menu, turn it on: **Safari → Settings → Advanced → Show features for web
   developers**.
2. Choose **Develop → Empty Caches**, or press `Option` + `Cmd` + `E`.

{{< /tab >}}

{{< /tabs >}}

Then open Healdan again and sign in.
