A document's history is a series of **versions**, and each version has **snapshots** along the way.

## Versions and Snapshots

- **The first number is the version.** `2.0` is version 2.
- **The second is a snapshot of that version.** `2.1` and `2.2` are snapshots on version 2's way.
- **Most changes make a snapshot:** saving the file again, editing its properties, moving it or renaming it.
- **A new version is a decision.** When you check a document in in the Classic Interface, tick **New version
  (otherwise a snapshot)** to start the next version. Otherwise it's saved as a snapshot, as the app's **Check In**
  does.

So version 2.3 is the third snapshot after version 2 was started, and the next new version will be 3.0.

## Saving a File as a New Version

Drag **one** file from your desktop onto a document's row in the app. If it is the same kind of file (the same extension,
in any case), choose **Save as Version 4 of # 10431**, where 4 is the next version number; a file of another kind is
filed as a new document instead. The file becomes the document's next version, under the document's own name. It's the same
as **Save as new version** in the Classic Interface. A document held by someone else, or on a computer, or locked can't
take it: see [Filing a Document](../../working-with-matters/filing-a-document/#dropping-a-file-on-a-document).

## Where to See Them

- **In the app,** select a document and choose the **Versions** tab in its details, which says how many there are in
  brackets, such as **Versions (4)**. It lists the whole timeline, newest
  first, every snapshot included, with who made each and when, and the comment they left. Each has its own **Preview**,
  which opens [Quick Look](../previews/) on that version, and **Download**, which saves that version's file (see
  [Downloading Documents](../downloading-documents/)). Quick Look's bar says which version it shows; **Open** is greyed
  out there, as it opens only the current file. A long timeline loads 200 versions at a time: choose **Show More
  Versions** for the rest.
- **The File version column** in the Classic Interface's documents list shows the version the file was last saved as.
- **The Versions tab** in the Classic Interface shows the same timeline. Preview or download any of them from there.
- **To go back to an earlier snapshot,** promote it from the Versions tab in the Classic Interface. That saves it as
  the latest.

## Finding a Version by Number

Type `#1234.2` in the search box and press Enter to go to version 2 of document 1234 as it stands, and `#1234.2.1` for
exactly snapshot 2.1. See
[Finding a Document by Doc #](../../finding-documents/finding-by-doc-number/).
