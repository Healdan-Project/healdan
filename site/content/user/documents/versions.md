A document's history is a series of **versions**, and each version has **snapshots** along the way.

## Versions and Snapshots

- **The first number is the version.** `2.0` is version 2.
- **The second is a snapshot of that version.** `2.1` and `2.2` are snapshots on version 2's way.
- **Most changes make a snapshot:** saving the file again, editing its properties, moving it or renaming it.
- **A new version is a decision.** When you check a document in, tick **New version (otherwise a snapshot)** to
  start the next version. Otherwise it's saved as a snapshot.

So version 2.3 is the third snapshot after version 2 was started, and the next new version will be 3.0.

## Where to See Them

- **The Version column** in the documents list shows the version the file was last saved as.
- **The Versions tab** shows the whole timeline, every snapshot included. Preview or download any of them from
  there.
- **To go back to an earlier snapshot,** promote it from the Versions tab. That saves it as the latest.

## Finding a Version by Number

`#1234.2` finds version 2 of document 1234 as it stands, and `#1234.2.1` finds exactly snapshot 2.1. See
[Finding a Document by Doc #](../../finding-documents/finding-by-doc-number/).
