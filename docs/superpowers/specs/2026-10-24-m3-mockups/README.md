# M3 mockups

The mockups the owner reviewed in M3's design session on 2026-10-24 (spec §5.8). They're HTML fragments that were shown inside the brainstorming tool's page frame, so a few colours come from CSS variables that frame defined; open them in a browser as they are.

- `save-to-healdan.html`: the Save to Healdan window, modelled on iManage's, with the ribbon above it. The owner's review changed three things since:
  - **The title bar** reads `Lease agreement #1234 v2.1`, as in `helper-and-title-bar.html`, not `#1234.2.1`.
  - **"My Favorites"** isn't a gap: favourites are CE's bookmarks (spec §9.3).
  - **"Save to local computer"** stays; the format choice is added under the properties (spec §5.6).
- `open-from-healdan.html`: the Open from Healdan window, and the warning when a document is checked out to you on another computer, with the owner's wording about edits not yet in Healdan.
- `helper-and-title-bar.html`: where the helper sits between the apps, the web page and the server, and the title bar's form.
