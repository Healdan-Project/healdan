Opening an existing document
  1. You double-click #1234 in the web page, which sends a healdan://open/1234 link to the helper.
  2. The helper checks the document out, downloads it to the cache and opens it in LibreOffice or Word.
  3. Each time you save, the helper sends the file up as a snapshot (v2.1 → v2.2).
  4. When you close it, the helper checks it in and tidies the cache.
