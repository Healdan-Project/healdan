Release 3 Documents from MacBook?

They're checked out to you on MacBook:

Laytime Calculation – MV Northern Star.xlsx# 10405ExcelSaved yesterday, 17:05
Report on Lease – Unit 4.odt# 10447LibreOfficeSaved Nov 14, 11:30
Grant Agreement – Draft.docx# 10414WordSaved Nov 12, 15:48
Changes on MacBook that haven't reached Healdan will be lost.

Once released, MacBook can't save to these documents again, and the work in its copies can't be carried on there.

If you get its copies back, upload each one as a new version of its document to rescue those changes.

If MacBook was lost or stolen, also revoke its sign-in in Signed-in Devices.
CancelRelease 3 Documents

The view

  • Columns: Title, Doc #, Version, Matter, Computer (the computer, with the app under it; Web Page for one checked out in a browser), Checked Out, and Edit Date, which is when it was last saved to Healdan. Author makes room for the two new ones.
  • Latest check-out first, as the server gives them, with no sorting by header, as Recent's lists.
  • The count beside the entry is how many you have checked out. It refreshes when you come back to the window, as the lists do.
  • Check-outs only. Documents locked with the Classic Interface's Lock don't appear.

Release…

  • It's the same action everywhere a document shows: the toolbar, a row's right-click menu, and Check-Out Info in the details. So a document checked out on MacBook can be released from a search too, not only from this view.
  • A check-out made in a browser releases at once, as today. One held on another computer asks first, with the warning in state 2.
  • A selection held on two computers gets one warning, with a list for each computer. Cancel has the focus, so Enter does nothing harmful.
