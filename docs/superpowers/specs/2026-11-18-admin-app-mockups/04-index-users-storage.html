What these change

  • Reindex runs straight through. Today's Indexer takes 500 documents every 30 minutes, so a large reindex takes hours.
  • You can also start one from a matter's or folder's page.
  • Disable, not Delete, for people. Disabling keeps their name on what they wrote and can be undone. No screen can undo a Delete, so I'd leave it out at first.

What stays as it is

  • Everything the Storage tab does today moves here, with the same rules.
  • A person who signs in through a provider has no password to reset, so the button doesn't show for them.
