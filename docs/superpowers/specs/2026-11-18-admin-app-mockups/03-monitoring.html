What each Errors option costs

  • A needs Healdan to catch errors as they happen and keep them in a small table of its own. Counts stay right after a restart or when the log file rolls over.
  • B only reads the log files, so it's simpler. The main log keeps about 30 MB, so an old error is gone once it rolls away, and one fault repeated 500 times fills the screen.

The Audit Trail

  • Sign-ins, documents and folders are already recorded by LogicalDOC.
  • Administration rows are new. Today only some admin changes leave a record: Healdan Settings and the client list leave none. The app would record every one, with its old and new value.
  • I'd go with A for Errors.
A

Grouped, and kept

One row per kind of fault, with counts and Mark Resolved.

B

Plain list from the log

Nothing new is stored, and the history is only as long as the log files.
