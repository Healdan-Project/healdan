Where do you change a list's columns?

Recent Documents, with the new default widths (Matter now shares the spare room and shows the matter's name). Each option shows the same list with its controls open. Click the one that feels right.

A

A menu on each heading, and nothing else

Right-click a heading (or Shift+F10 on it) for a menu that does everything: sort, resize, move, hide, and a Show Columns submenu with a tick for each column.

Pros

  • One place, nothing added to the screen
  • Every action is about the heading you're on

Cons

  • Hard to discover: nothing says headings have a menu
  • Adding three columns means opening the menu three times
  • A new column lands at the end; ordering is Move Left, Move Left…
B

A Columns button that opens a panel

A small button at the end of the heading row opens the whole set at once: the shown columns in their order (drag them, or Move Up and Move Down), then the rest to tick. Headings themselves only sort, and resize by dragging their edges.

C

Both: a short menu on each heading, and the Columns panel (my pick)

The heading's menu does what's about that column (sort, resize, move, hide) and ends with Choose Columns…, which opens B's panel. The button at the end of the heading row opens the same panel, so it's easy to find.
