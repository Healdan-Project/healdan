# The Demo Firm's Sources

This folder holds the text sources of the demo stack's sample files, one per row of the catalogue below, each in
the format that describes it best. `python3 docker/demo/build.py` builds them into `../files/` with the LibreOffice
in the Healdan image (its docstring says which source makes which file), and `../manifest.json` files them as the
firm's users, on the timeline's days. Every word, name, address and figure is invented for the demo: British
English, `.example` email domains, phone numbers only from 01632 960000–960999, and no real people, companies,
case law, court forms or Land Registry forms. Printed dates assume a first start on Thursday 29 October 2026, so
day -1 is Wednesday 28 October 2026. Read `letterhead.css` before writing an `.html` source.

## Catalogue

"Day" is the manifest's `day`. A row whose folder says "new version" or "snapshot" is a `checkin` over an earlier
row's document, not a document of its own. An email's attachments are other rows' built files, so build those rows
first.

The firm's own letters (rows 5, 11, 30, 40, 45, 60 and 66), memos and attendance notes (rows 3, 6, 17, 20, 36, 55
and 62) and policies (rows 61 and 64) use the Ashcombe Reeve letterhead: copy the head, the letterhead block and the
footer from `saltmarsh-letter-to-owners.html`. Agreements, court documents and wills the firm drafts have a plain
heading of their own, without the letterhead, and every other party's document has that party's own plain heading.
