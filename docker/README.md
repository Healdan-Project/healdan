# Healdan's Docker Stack

This directory holds Healdan's container build and compose stack. How to use them is in the docs:

- **Running Healdan:** the [Install](https://docs.healdan.com/install/) manual covers the quick start, configuration,
  reverse proxies, backup and restore, upgrading and troubleshooting.
- **Working on Healdan:** the Developer Guide's [Running a Development Stack](https://docs.healdan.com/developer/development-stack/),
  [Tests](https://docs.healdan.com/developer/tests/) and [Continuous Integration](https://docs.healdan.com/developer/continuous-integration/).

The design is in [the spec](../docs/superpowers/specs/2026-10-15-docker-compose-stack-design.md).
